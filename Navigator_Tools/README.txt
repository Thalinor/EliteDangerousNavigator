Part of the Navigator suite. A notepad and a calculator in one panel. It reads nothing from the game and sends nothing anywhere.

NOTES TAB
- Write in the box. The note saves itself a moment after you stop typing, when you leave the tab and when EDMC closes (Save does it at once).
- Left and right arrows move between notes; tap the title in the middle (1/3  first line of the note) for a list of all notes; New adds a blank note (an empty last note is reused).
- Delete needs two taps within three seconds (the button says "Sure?"), so a stray touch never loses a note. The last remaining note is cleared, never removed.
- Notes live in one file: EDMC's data folder \Navigator_Tools\notes.json.

CALCULATOR TAB
- Basic: touch keypad (C, backspace, %, +/-, the four operations) or type into the display and press Enter. A number typed after a result starts a new sum; an operator carries on from it. 50% means 0.5.
- Game: pick a calculation with the arrows or tap its name for a list, then fill in the boxes (sums such as 12*3 work in the boxes too). Answers appear as you type.
    Jumps and fuel  - distance, jump range, fuel per jump, tank: jumps, fuel needed, tanks, refuel stops
    Travel time     - jumps, seconds per jump, refuel stops, minutes per stop: total and average time
    Trade profit    - units, buy, sell: total profit, profit per unit, margin, total cost
    Earnings per hour, Mining haul (value, credits and tons per hour), Ly and Ls (1 Ly = 31,557,600 Ls)
  Fleet carrier fuel and upkeep formulas are not included yet: they need exact figures from the game.

LOOK
- Same panel header as the other Navigator panels (Normal Text), Highlighted tabs and buttons, the same small buttons.
- Every tab is the same height, so EDMC's window does not jump when you switch tabs.
- Typing boxes are solid (black in the Transparent theme) so what you type stays readable over the game.

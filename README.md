# Elite Navigator

A free, open-source companion program for Elite Dangerous on Windows, with a new Qt interface, a shared data service and built-in panels.

**Status:** in development. Nothing is released yet. This page is the future home of the project, and the source will be published here under the GPL-3.0-or-later licence, together with a digitally signed program, when it is ready.
